# V.A.D.A.++ — A Data Science Learning System

A 12-month, evidence-based self-learning system for data analytics and data science: a curriculum, eight flagship domain projects, a learning-science-backed study method, and the tracking tools to actually follow through on all of it — one GitHub-hosted, free-to-host site.

This exists because most of the good material for learning data science is already free. The hard part was never finding a course — it's sequencing it well, studying it in a way that actually retains, and shipping enough real projects to prove it. This system is built to solve those three problems specifically.

## The four pieces of this system

1. **[Methodology](methodology/index.md)** — the V.A.D.A.++ loop (Visual map → Apply → Discuss/teach-back → Audio reinforcement), re-weighted toward what the learning-science evidence actually supports: retrieval practice, spacing, interleaving, and deliberate error practice, with sourced citations throughout.
2. **[Curriculum](curriculum/index.md)** — 12 months, compressed where you already have background (Python/SQL/Power BI/stats), expanded where the hiring signal actually concentrates (machine learning and shipped projects).
3. **[Projects](projects/index.md)** — 8 flagship, real-data project blueprints spanning EDA, dashboards, ML modeling, and one already has a working artifact ([Gold](projects/06-gold-commodities-regimes.md)) to build from.
4. **[Tools](tools/progress-tracker.md)** — a progress dashboard with a streak counter, a spaced-repetition micro-problem deck, and an interleaved drill bank — all running entirely client-side, no backend required.

Plus the connective tissue: an **[Accountability](accountability/index.md)** page on the #100DaysOfData habit mechanism and how to join a real group project, and a **[Mistake Library](mistake-library/index.md)** that turns every real error into a reusable retrieval card.

## Why this is structured the way it is

Two research threads sit underneath every design choice on this site:

- **What to study, in what order** — compressing prerequisites you already have, sequencing toward mastery gates, and shipping a real project every month rather than only consuming content. See the [curriculum overview](curriculum/index.md) for the evidence (project-based learning meta-analyses, hiring-signal research on portfolios).
- **How to study it so it actually sticks** — retrieval practice beats rereading, spacing beats cramming, interleaving beats blocking (once you're past the beginner stage), and explaining out loud beats silently reviewing. See the [methodology section](methodology/index.md) for the full, cited research behind each claim.

## Quick start

1. Read [V.A.D.A.++ overview](methodology/index.md) (15 minutes) — it changes how you approach everything after it.
2. Open [Month 1](curriculum/month-01-python-pandas.md) and start the first week.
3. Bookmark the [Progress Dashboard](tools/progress-tracker.md) and log your first session today.
4. Add your first entries to the [Mistake Library](mistake-library/index.md) as soon as something goes wrong — not at the end of the month.

## A note on this site itself

Everything interactive here (the dashboard, the streak counter, the flashcard deck) runs in your browser using `localStorage` — nothing is uploaded, there's no account, and it works the moment this repo is deployed to GitHub Pages. Clearing your browser's site data resets your tracked progress, so avoid browsing this site only in a private/incognito window if you want progress to persist.
