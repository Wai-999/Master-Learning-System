# Projects — Overview & Portfolio Rules

Eight flagship project blueprints across eight domains. Full portfolio rules live on the [curriculum overview](../curriculum/index.md#what-hiring-ready-actually-means-here) — the short version: 4–8 finished projects, no sandbox datasets, spanning EDA/storytelling, an interactive dashboard, an evaluated ML model, an end-to-end deployment, and one collaborative piece.

## The project ladder — how to approach any of these

Don't attempt a flagship project cold. Climb it in four rungs, each adding exactly one new difficulty:

1. **Guided clone** — follow a tutorial on similar data, end to end, to learn the shape of the problem.
2. **Same technique, new dataset** — repeat the technique on a dataset the tutorial didn't use. This is where you find out what you actually understood vs. what you copied.
3. **Open-ended question, messy data** — pose your own question on real, imperfect data with no answer key.
4. **End-to-end shipped piece** — EDA → model → written narrative → (where relevant) deployment, polished enough to put in front of a stranger.

The eight blueprints below are written at the level of rung 3–4 — the open-ended question and the shape of a finished piece. If a project stalls, that's the signal to **drop back one rung**, not to push through in frustration (this mirrors the MOOC-completion research: engagement with structured, incremental steps predicts finishing; jumping straight to the hardest version predicts dropping out).

## Choosing which ones to prioritize

If the goal is breadth for a general analyst/data-scientist role, **Finance** and **Real Estate** have the widest hiring relevance and the cleanest, best-documented free data. If the goal is a macro/commodities-adjacent role, **Gold** and **Oil & Energy** are the strongest signal. **HR/People Analytics** is the highest-ROI single starter project if you want one clear "hire me" classification-plus-survival-analysis piece, since survival analysis is a genuine differentiator few entry-level portfolios include. **Politics** demonstrates comfort with multi-source, multi-indicator public data, which transfers well to policy/research-adjacent roles.

You are not expected to build all eight to flagship depth in one pass through the [curriculum](../curriculum/index.md) — [Month 10](../curriculum/month-10-domain-specialization.md) is explicitly for going deep on 1–2 that most interest you, on top of whichever ones you build earlier as your monthly milestone deliverables.
